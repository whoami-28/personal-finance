# Personal Finance Web Application

Минималистичный сервис для ведения личного бюджета и учета финансов, разработанный на стеке HTML5, CSS3 и Vanilla JavaScript. Интерфейс выполнен в монохромной темной теме (оттенки серого) без применения сторонних библиотек и иконочных шрифтов.

---

## 📌 Функциональные возможности

* **Учет операций**:
  * Добавление доходов и расходов с указанием названия, суммы, категории и даты.
  * Редактирование существующих записей с автоматической подстановкой данных в форму.
  * Удаление отдельных операций.
* **Категории**:
  * Доходы: *Зарплата*, *Фриланс*, *Инвестиции*, *Подарки*, *Другое*.
  * Расходы: *Продукты*, *Жилье*, *Транспорт*, *Развлечения*, *Здоровье*, *Другое*.
  * Динамическое переключение списка категорий в форме в зависимости от выбранного типа операции.
* **Баланс и сводка**:
  * Автоматический пересчет текущего финансового баланса, суммарных доходов и расходов.
* **Поиск, фильтрация и сортировка**:
  * Полнотекстовый поиск по наименованию операции.
  * Фильтрация по типу (*Все*, *Только доходы*, *Только расходы*).
  * Фильтрация по конкретной категории.
  * Сортировка: по дате (*сначала новые*, *сначала старые*) и по сумме (*по убыванию*, *по возрастанию*).
* **Аналитика и статистика**:
  * Расчет процентного соотношения трат и поступлений по категориям.
  * Индикаторы долей с визуальными шкалами прогресса.
  * Переключение аналитики между доходами и расходами.
* **Сохранение состояния**:
  * Персистентное хранение всех данных в `localStorage` браузера (данные не сбрасываются после перезагрузки страницы).

## 🖥 Архитектура интерфейса

Приложение разделено на ключевые функциональные зоны:

| Секция | Описание |
| :--- | :--- |
| **Сводка** | Верхние карточки с общим балансом, суммой доходов и суммой расходов. |
| **Боковая панель (левая)** | Форма ввода/редактирования операции и блок аналитики по категориям. |
| **Основная панель (правая)** | Панель фильтров, поиска и сортировки, а также интерактивная таблица истории операций. |

## 🛠 Стек технологий

* **HTML5**: семантические элементы (`<main>`, `<aside>`, `<section>`, `<header>`, `<table>`).
* **CSS3**: CSS Custom Properties (переменные для палитры), CSS Grid, Flexbox, адаптивность под мобильные устройства.
* **JavaScript (ES6+)**:
* Структуры данных: массив объектов `transactions`.
* Методы массивов: `filter()`, `map()`, `reduce()`, `sort()`, `findIndex()`.
* Браузерные API: Web Storage API (`localStorage`), DOM API.

## 🚀 Установка и запуск

1. Склонируйте репозиторий:
```bash
git clone [https://github.com/whoami-28/personal-finance.git](https://github.com/whoami-28/personal-finance.git)
cd personal-finance

```


2. Запустите проект:
* **Напрямую**: откройте файл `index.html` в любом современном веб-браузере.
* **Через локальный веб-сервер**:
```bash
# Python 3
python -m http.server 8000

```


После запуска перейдите по адресу: `http://localhost:8000`.
